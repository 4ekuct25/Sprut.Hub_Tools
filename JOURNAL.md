## 2026-08-04 — шаблон VirtualThermostat.json отстал от исходника на две версии

**Что:** пересобран `VirtualThermostat/VirtualThermostat.json` (`scenarioTemplate.data` = содержимое
`source/VirtualThermostat.js`, 3.11.0-ac → 3.11.2-ac); в `README.md` поднята версия в заголовке
форка (там оставалось v3.11.0-ac) и восстановлен порядок чейнджлога — 3.11.2 стояла между 3.10.0
и 3.11.1, метка «(текущая)» уехала в середину списка.

**Почему:** в коммитах 3.11.1-ac и 3.11.2-ac (15–16 июля) выполнены пункты 1, 3 и 5 чек-листа из
`VirtualThermostat/CLAUDE.md`, но пропущены пункты 2 (README) и 4 (пересборка шаблона). Экспорт —
это то, что импортируется в хаб, так что при импорте `VirtualThermostat.json` в хаб уехал бы код
3.11.0-ac: без правок скорости вентилятора в удержании у цели и без учёта направления разницы.
Расхождение молчаливое — ни тесты, ни хаб о нём не сообщают, тесты гоняются по `source/`.

**Как проверено:** прогон `bun run cli run VirtualThermostat --root ..` до и после — 160 passed,
0 failed (2 файла тестов). Перезапись json проверена на минимальность диффа: round-trip
`json.dumps(ensure_ascii=False, indent=2)` без хвостового перевода строки байт-в-байт совпадает
с исходным файлом, поэтому в диффе изменилось ровно одно поле (`data`), `data == source` побайтно,
версия внутри шаблона — 3.11.2-ac. Порядок версий в README проверен скриптом: 25 версий, строго
по возрастанию, «(текущая, форк)» ровно одна и на последней.

**Откат:** `git checkout -- VirtualThermostat/README.md VirtualThermostat/VirtualThermostat.json`
(изменения не закоммичены на момент записи); резервная копия шаблона — `/tmp/VirtualThermostat.json.bak`.

**Открытые хвосты:**
- Противоречие в правилах: корневой `CLAUDE.md` запрещает править `.json` сценариев («экспорты из
  UI, пользователь обновляет сам»), а `VirtualThermostat/CLAUDE.md` (п. 4) требует их пересобирать.
  Пересборка сделана по явному решению пользователя; правила нужно свести к одному.
- `scenarioTemplate.desc` в экспорте — короткий текст из UI хаба, не выводится из `info.description`
  и ссылается на v3.2-ac. Не трогали: это поле пользователь ведёт в хабе.
- `tools/thermo24.py` (вне git) и `.claude/skills/spruthub-thermostat-24h/scripts/thermo24.py`
  сейчас идентичны побайтно, но это две копии одного скрипта — кандидат на рассинхрон.
